# 漢字4択クイズ

ブラウザで動く、明るいデザインの漢字4択クイズです。

## すぐ使う方法

### 方法A: `index.html` を直接開く（最短）
このアプリは API 通信を使っていないため、`index.html` をダブルクリックしてそのまま使えます。

### 方法B: ローカルサーバーで開く
`http://127.0.0.1:4173` は**ローカルサーバーを起動したときだけ**使えます。

```bash
python3 -m http.server 4173
```

起動後に以下を開いてください。

- http://127.0.0.1:4173

## うまく開けないとき

- `http://127.0.0.1:4173` が開けない
  - サーバーが起動していない可能性があります。上のコマンドを先に実行してください。
- `python3` がない
  - `python -m http.server 4173` を試してください。
- 会社PCなどでポート制限がある
  - `index.html` を直接開く方法Aを使ってください。

## 機能

- 4択クイズ
- レベル選択（漢検4級 / 漢検準2級 / 漢検2級）
- 正誤表示とわかりやすい解説
- 進捗・スコア表示
- リトライ対応
